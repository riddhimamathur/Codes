📘 Dijkstra’s Algorithm Study Guide
---------------------------------------------------------------------------------------------------
1. Problem Definition
Input: A weighted graph (non-negative edge weights) and a source vertex.
Output: The shortest path distance from the source to all other vertices.
---------------------------------------------------------------------------------------------------
2. Key Idea
Greedy approach: At each step, pick the vertex with the minimum tentative distance that hasn’t been processed yet.
Relaxation: Update the distances of its neighbors if a shorter path is found.
---------------------------------------------------------------------------------------------------
3. Algorithm Steps
Initialize distances:

dist[source] = 0

dist[others] = ∞

Use a priority queue (min-heap) to always pick the vertex with the smallest distance.

For each neighbor of the current vertex:

If dist[current] + weight < dist[neighbor], update dist[neighbor].

Repeat until all vertices are processed.
---------------------------------------------------------------------------------------------------
4. Time Complexity
Using adjacency list + min-heap : 𝑂 (( V + E ) log V )
Where:
𝑉 = number of vertices
𝐸 = number of edges
---------------------------------------------------------------------------------------------------
5. Example
Graph:

Code
    (0)
   /   \
  4     1
 /       \
(1)---2---(2)
Source = 0

Shortest distances:

dist[0] = 0

dist[1] = 3 (0 → 2 → 1)

dist[2] = 1 (0 → 2)

#include <bits/stdc++.h>
using namespace std;

void dijkstra(int V, vector<vector<pair<int,int>>> &adj, int src) {
    // Distance array
    vector<int> dist(V, INT_MAX);
    dist[src] = 0;

    // Min-heap priority queue (distance, node)
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    pq.push({0, src});

    while(!pq.empty()) {
        int d = pq.top().first;
        int u = pq.top().second;
        pq.pop();

        // Skip if already found a better path
        if(d > dist[u]) continue;

        // Relax neighbors
        for(auto edge : adj[u]) {
            int v = edge.first;
            int weight = edge.second;

            if(dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({dist[v], v});
            }
        }
    }

    // Print shortest distances
    cout << "Vertex   Distance from Source\n";
    for(int i = 0; i < V; i++) {
        cout << i << "\t" << dist[i] << "\n";
    }
}

int main() {
    int V = 5; // number of vertices
    vector<vector<pair<int,int>>> adj(V);

    // Example graph edges (u, v, weight)
    adj[0].push_back({1, 4});
    adj[0].push_back({2, 1});
    adj[2].push_back({1, 2});
    adj[1].push_back({3, 1});
    adj[2].push_back({3, 5});
    adj[3].push_back({4, 3});

    int src = 0;
    dijkstra(V, adj, src);

    return 0;
}
