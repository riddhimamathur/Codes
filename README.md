## ▶️ How to Run

### C Programs

Compile a C program using GCC:

```bash
gcc filename.c -o program
./program
```

### C++ Programs

Compile a C++ program using G++:

```bash
g++ filename.cpp -o program
./program
```

On Windows, run the generated `.exe` file.
